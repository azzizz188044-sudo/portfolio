Aziz Ergashev

Men biznes jarayonlarini avtomatlashtirish uchun Telegram botlar ishlab chiqaman. Har bir loyihada kod sifati, xavfsizlik va foydalanuvchi qulayligini birinchi o'ringa qo'yaman.

Asosan Python, Django, Django REST Framework, PostgreSQL va REST API texnologiyalari bilan ishlayman. Web saytlarni serverga qo'yish, ma'lumotlar bazasini loyihalash, API ishlab chiqish hamda xavfsiz va tezkor backend tizimlarini yaratish mening asosiy ishim.

Agar sizga web sayt, REST API, backend tizim yoki Telegram bot kerak bo'lsa, men sizning g'oyangizni zamonaviy va ishonchli dasturiy yechimga aylantirishga yordam beraman. G'oyangiz hali to'liq shakllanmagan bo'lsa ham, bemalol bog'lanishingiz mumkin — uni birgalikda rejalashtirib, ishga tushiramiz.
